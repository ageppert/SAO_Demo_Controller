# SAO DEMO CONTROLLER

A Microcontroller for your smarter-than-average SAO!

The SAO Demo Controller makes it convenient to bring life to your advanced I2C-based SAO! Use this to test and demonstrate your new design even when your host badge isn't ready to control the SAO. Maybe this is better referred to as a micro badge for developing SAOs.

CAUTION: Do not plug this into your host badge and USB-C at the same time!!!

Follow this project at: https://hackaday.io/project/198034-sao-demo-controller 

Hardware Version 3.X
This one is protected for multiple power input options simultaneously with far more advanced power options, protection, and routing. This one is a perfect companion for an Etch sAo Sketch, Mac SAO, or any other SAO! See schematic for details and instructions.
